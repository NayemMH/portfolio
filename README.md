# portfolio

Personal portfolio of **Md. Mahadi Hassan Nayem** — Data Scientist, Statistician, and author of the
[`drglm`](https://cran.r-project.org/package=drglm) R package.

**Live site:** <https://mhnayem.github.io/portfolio/>

---

## About this repository

A single-page static site. No framework, no build step, no dependencies beyond Google Fonts —
`index.html` contains all markup, styles, and scripts inline.

```
index.html          Whole site (HTML + CSS + JS)
profile.jpg         Portrait used in the hero and profile sections
life-events/        Photos for the Life Events timeline
```

To run it locally, open `index.html` in a browser, or:

```bash
python -m http.server 8000
```
